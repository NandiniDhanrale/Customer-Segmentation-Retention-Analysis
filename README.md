# Customer Segmentation & Retention Intelligence

Reproducible analysis of UCI Online Retail transactions using Python, DuckDB, scikit-learn, Streamlit and Plotly.

See the project files and run `python -m src.pipeline` after downloading the UCI Online Retail Excel workbook to `data/Online Retail.xlsx`. Launch with `streamlit run app.py`.

Dataset: https://archive.ics.uci.edu/dataset/352/online+retail (CC BY 4.0). Historical transactions cover December 2010 to December 2011. Cancellations and nonpositive transactions are excluded; metrics represent accepted gross sales, not refund-adjusted net revenue. Customer identifiers in the dataset are pseudonymous.
